# Handoff: slots (PR 3c)

## Endpoint changes
| Method | Path | Auth | Result |
|---|---|---|---|
| GET | `/api/matches/{shareId}/slots` | public | `200 {"teams":[{"team":"a","capacity":9,"players":[{"name","avatarUrl","isGuest","guestOf"}]},{"team":"b",...}]}`, `Cache-Control: public, max-age=30`; `404 match_not_found`. |
| GET | `/api/matches/{shareId}/slots/mine` | session | `200 {"joined":false}` or `{"joined":true,"team":"a","guests":["An"]}`, `private, no-store`; `401`; `404`. |
| POST | `/api/matches/{shareId}/slots` | session | Body `{"team":"a"\|"b","guests":["An"]}` (guests optional, ≤ 2, 1–40 chars each after trimming). `201` with the own-place view. `409 team_full` (the whole group must fit), `409 already_joined`, `409 match_started`; `422 {"error":"invalid_slot_request","field":"team"\|"guests"}`; `400 invalid_request`; `413 payload_too_large`; `401`; `404`. |
| DELETE | `/api/matches/{shareId}/slots/mine` | session | Releases the player's place and their guests. `204` (also when not joined); `409 match_started`; `401`; `404`. |

Players are listed in the order they joined. A guest has `avatarUrl: null`, `isGuest: true` and `guestOf` set to the holder's display name. Capacity: team A gets `ceil(slotCount / 2)`, team B `floor(slotCount / 2)`.

## Database changes
Migration `20261007000000_create_slots.sql` (approved by Long 2026-10-05): `slots` with one row per place (own place or named guest), `released_at` instead of deleting, and a partial unique index allowing one own active place per user per match. Capacity and the 2-guest limit are enforced in the claim transaction (READ COMMITTED) under `SELECT ... FOR NO KEY UPDATE` on the match row.

## Other API changes
Every request body is limited to 16 KiB; larger bodies get `413 {"error":"payload_too_large"}` (also on `POST /api/matches`). Names (display names, guest names) drop zero-width and other invisible format characters.

## Frontend actions
Done in this PR:
- `TeamSlots` on `/m/[shareId]` shows both teams.
- When signed out it shows a sign-in link back to the match. When not joined it shows the join form (team picker, up to 2 guests); when joined, it shows the player's own place and a leave button.
- It calls the API from the browser through the `/api` proxy, and refreshes the roster on load and after every action, because the page HTML is cached for 30 seconds.
- If the roster cannot be loaded on the server, the page still renders with empty teams and the client refreshes them; if the player's own place cannot be loaded, a retry button is shown.
