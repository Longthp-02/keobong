# Frontend Handoff

## What changed
Attendance polls made by Bot DaGhep. New page `/p/[shareId]` (`app/p/[shareId]/page.tsx`, `components/PollBoard.tsx`). The privacy policy covers poll answers and group rosters.

## Endpoints affected
- `GET /api/polls/{shareId}`: new, public; reads the session cookie when present.
- `PUT /api/polls/{shareId}/answers`: new, needs sign-in.
- `POST /api/bot/reminders/run`: the response gains `nudged`.

## Request changes
- `PUT … /answers` body: `{"answers":[{"day":"YYYY-MM-DD","attending":true}]}`, 1–7 items, days of the poll only.

## Response changes
- Both return the poll view: `title`, `days`, `playTime` (HH:MM, or `null` for polls made before 2026-10-26), `closesAt`, `closed`, `counts` (`[{day, yes}]`), `players` (`[{name|null, answers: {day: bool}}]`), `mine` (the viewer's answers, `null` when signed out). `Cache-Control: private, no-store`.

## Validation / auth / error changes
- 404 `not_found` (unknown or malformed id), 401 `unauthenticated` (answering signed out), 409 `poll_closed`, 400 `invalid_day` / `invalid_request`.

## Frontend actions required
Done in this PR: the page renders per request (it shows the viewer's answers) and sends answers through the site's `/api` proxy.

## Example payloads
`PUT /api/polls/abcDEF12/answers` `{"answers":[{"day":"2099-10-03","attending":true},{"day":"2099-10-04","attending":false}]}` → 200 with the poll view.
