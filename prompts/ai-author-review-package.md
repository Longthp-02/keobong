# AI Author Review Package

Prepare a review package for the changes you just made. Do not modify any code while preparing it.

Include:
1. Original requirement summary
2. Changed files in logical reading order (domain → application → adapters → tests → docs)
3. Risk areas and why
4. Proof it works: commands run and their output; anything not run
5. The full diff
6. Known weaknesses, shortcuts or `TODO: verify` items — do not hide them
